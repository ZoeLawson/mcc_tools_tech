# For Students

This is the class repository.

`.github` contains files that define GitHub automation. Do not touch.

`Handouts` contains additional PDF files that provide additional information not associated with any specific class session.

`mcchandout` eventually contains PDFs automatically generated from your DITA source files.

`revealjs` contains  CSS and Javascript files that make the presentations work. Do not touch.

`Week*` folders contain  the presentation for the week (an HTML file), occasionally additional information in a PDF, and sometimes example files. Your homework will go into these folders in a `Homework` subfolder.

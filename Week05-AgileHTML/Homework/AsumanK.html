A TECHNICAL WRITING CHECKLIST

This page summarizes important principles for technical writing. The checklist helps you write clearly, use the active voice, and organize information so readers can follow instructions easily.

Key Writing Principles

  • Use the active voice.
  • Address the reader directly when appropriate.
  • Avoid jargon, slang, and marketing language.
  • Keep paragraphs short and clear.
  • Be consistent with terms and formatting.

steps for Clear Instructions

  1. Explain what the user needs to know first.
  2. Show the command or action clearly.
  3. Describe what the system displays.
  4. Provide examples that users can copy exactly.
  5. Test all instructions before publishing.

Checklist Summary Table

Guideline What to Do Why It Matters
Active Voice Write direct, clear sentences. Improves readability.
Second Person Address the reader as "you" when appropriate. Keeps focus on user actions.
Consistency Use the same terms throughout the document. Prevents confusion.
Testing Verify all examples and instructions. Ensures accuracy.

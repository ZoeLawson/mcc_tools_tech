## Images:
Since markdown is just a text file, if you want to insert an image, you pretty much just make a link to it, just put an exclamation point before it.

I'm going to do a link to an image:

![Pelican flying in front of Naples Pier](./Week06-Homework/RoffoCopyrightNaplesPier.IMG_0930.jpeg")                      (../relative/path/to/image.png)
I'm not sure if that path is right, as I'm still fuzzy on relative paths and need clarification on that. 

It may seem strange to put text in with an image, but it serves two important purposes:
• Alternative text - if something goes wrong and the image doesn't display, this text displays instead. YES, I've seen that happen!
• Accessibility - if you use a screen reader, this text explains what the image contains.

Columns are separated by pipes. Header rows can be separated by a line of hyphens.

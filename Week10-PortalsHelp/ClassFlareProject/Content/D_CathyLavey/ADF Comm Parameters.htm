ADF Comm Parameters

This topic describes the communication parameters used by the ADF.

The USB interface to the ADF is an FTDI FT232R Serial to USB chip; when plugged into a host system, it will appear as one or more serial ports. The Windows driver for this device is available from the website: http://www.ftdichip.com/FTDrivers.htm.

For ADF G7 (dismount) and G8 (unattended ground sensor, vehicle mount), four serial ports will appear. The first port is the console. The second and third are for BioMimetic Systems’ use. The fourth port is for sensor output, as documented in the section below, on messages from the ADF to the host system. Display or data logging applications should monitor this fourth com port.

The communications parameters are documented in the SWADF comm parameters below. All messages (both in and out) are followed by a “\r\n” (0x0d0a).

Hardware Status Report

This message is sent by the ADF as a response to a status request by the host (see Hardware Status Request on page 5) or during a failure of the self-test TODO (see section). A failure is indicated by a zero at the appropriate bit position.

The message is formatted as follows:

$h<8 hex digits>

The bit definitions from low bit to high bit are:

  • 0x00000001 – if clear, indicates a failure of the primary analog board (analog ADF systems only)

  • 0x00000002 – if clear, indicates a failure in the secondary analog board (analog ADF systems only)

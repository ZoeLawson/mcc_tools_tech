Add a heading to a Flare topic

When you create a new topic, you can set the title, so the topic title will probably already exist.

Flare topics are just HTML files, so you can add headings to individual topics.

  • The first element of the topic is a H1 element. You can change your topic title.
  • To add a new heading, insert a paragraph and then select the heading level (h1, h2, h3, h4, h5, h6) from the Styles list on the Home ribbon.

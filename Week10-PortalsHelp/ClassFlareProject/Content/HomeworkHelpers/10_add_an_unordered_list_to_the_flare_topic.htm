Add an unordered list to the Flare topic

Since Flare topics are just HTML you can add an ul element in the text view, or you can use the Bullet List tool.

  1. Add a paragraph to your Flare topic.
  2. With your cursor in the paragraph, select the Bullet List.

    The paragraph becomes a paragraph in a list item in an unordered list.

  3. Press Enter to add a new list item.
  4. To exit the list, you can press Enter again on an empty list item.

    You can also click the List Bullet icon again to toggle the list off.

Similar to HTML, you can put lists inside of lists. In Flare, you can use the Move context menu to control the nesting of items. You can also use the List Actions.

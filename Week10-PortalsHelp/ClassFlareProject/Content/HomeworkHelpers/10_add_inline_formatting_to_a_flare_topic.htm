Add inline formatting to a Flare topic

Since the base of Flare is HTML, you can just use the formatting tools

It looks like whoever designs your Flare template can design additional CSS styles that you might apply to your content. That will be unique to your environment.

  • For basic formats, such as bold and italic, select the text and click the appropriate formatting from the Font section of the Home ribbon.
  • Additional inline elements are available from the Style list on the Home ribbon.

For example, I imported DITA topics. This created span elements with the class attribute set to the DITA element name. This means you have access to the following span styles:

span.filepath
File names and computer paths.
span.keyboard
Name of keys or other things you press on a keyboard.
span.uicontrol
Things you click in a UI, such as button or field names.
span.wintitle
The name of dialog boxes or windows.
span.xmlatt
The name of an XML attribute. I've configured the styling to automatically prepend an @ symbol.
span.xmlelement
The name of an XML element. I've configured the styling to automatically wrap the text in angle brackets.

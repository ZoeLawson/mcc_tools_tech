Insert an external link in the Flare topic

You often need to reference external websites when writing.

  1. Have your cursor where you want to insert the link in your Flare topic. Alternatively, you can enter the text for the link and select that text.
  2. From the Insert ribbon, click Hyperlink.
  3. In the Insert Hyperlink dialog box, select Website from the Link to list.
  4. Enter the URL in the Website field.
  5. If it is not already populated, enter the Link Text.

  6. Click OK.
You link is inserted.

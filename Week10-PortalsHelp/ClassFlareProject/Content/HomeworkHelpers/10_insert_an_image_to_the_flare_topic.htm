Insert an image to the Flare topic

Images in Flare are added by reference, but also need to be a part of your project.

Make sure your image is created before you start.

  1. Add your image to the project. The easiest way to do this is to drag the image into the appropriate folder in the Flare Content Explorer panel.

    In the class project, images are stored in the Content/Resources/Images folder in the Content Explorer.

    For facts to file and forget, this folder is also accessible from Windows File Explorer: mcc_tools_tech\Week10-PortalsHelp\Homework\Content\Resources\Images. Therefore you can just move files into this folder. You can add sub-folders to organize the images as you need.

  2. Make sure your cursor is where you want to insert the image.
  3. From the Insert ribbon click Image.
  4. In the Insert Image dialog box, navigate to the image in the project and select it.

  5. Click OK.
The image is added to your topic.

Example Flare Topic

Flare is just HTML.

To use all the fancy features of Flare, such as conditional text and snippets, you really need to use the Flare tool. But, the raw source is just HTML.

If you don't have access to Flare, you can still do the basics to edit your topic in a text editor.

The following is the results of the example shown.

Git and MadCap Flare

MadCap Flare has an integration with Git built in.

If you open a project that is inside of a cloned Git repository, automatically connects and picks up what is going on.

Files with a red check mark indicate that the file has changed and needs to be committed.
Files with a green plus sign indicate that it's a new file to be added.

Both of these can be seen in the content explorer as well:

Add files to Git

  1. Select File > Source Control > Add.

  2. Provide a Comment and confirm the correct set of files is selected.

  3. Click Commit.

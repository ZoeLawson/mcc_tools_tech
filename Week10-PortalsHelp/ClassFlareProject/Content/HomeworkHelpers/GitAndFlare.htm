Git and MadCap Flare

MadCap Flare has an integration with Git built in.

If you open a project that is inside of a cloned Git repository, automatically connects and picks up what is going on.

Files with a red check mark indicate that the file has changed and needs to be committed.
Files with a green plus sign indicate that it's a new file to be added.

Both of these can be seen in the content explorer as well:

Commit Files

  1. Select one of the following:

    • File > Source Control > Add
      This option is available only if there are new files to add.

    • File > Source Control > Commit

      This option is available only if there are saved changed files.

  2. Click Show all Candidates ().

    If you do not click this option, you will only be able to add or commit the file you are currently editing.

  3. Confirm the correct set of files is selected.

  4. Provide a Comment.

  5. Click Commit.

Push Changes to GitHub

  1. Commit all of your changes.

    If you have unsaved changes, does not finish the push.

  2. On the Source Control ribbon, click Push.
